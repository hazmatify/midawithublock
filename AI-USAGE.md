# AI Usage

MIDA is made by a human, iTz_Nao, as a labour of love for Destiny 2.

AI was a tool I used along the way, like a search engine. It did not replace me. The ideas, the design, the features and a lot of the code was not made by AI.

## What I did

- Came up with MIDA and decided what it should be.
- Wrote my own code, starting with the first version of the app, and kept writing and changing it the whole way through.
- Designed everything you see: the layout, the colors, the gradient, the animations and the wording.
- Chose every feature and every change.
- Tested MIDA in real use, including while playing Destiny 2.
- Even edited and checked this very file which was made by AI.

## How I used AI

I used an AI coding assistant (Claude, by Anthropic) as a tool to help me:

- Write code for features I planned, such as the show/hide hotkey, the sign-in logic, the update check and the installer setup.
- Clean up and simplify the code.
- Track down and fix bugs.
- Write documentation, such as the README, LICENSE, AI-USAGE and contributing guide.

I asked for every AI change and tested the results myself.

## What MIDA does not do

MIDA does not use AI while it runs, and it sends no data to any AI service.
