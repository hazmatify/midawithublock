# Contributing to MIDA

Thanks for helping! MIDA is source-available, not open source. Please read [LICENSE](LICENSE) first.

## How to contribute

1. Fork https://github.com/itznao/mida on GitHub.
2. Make your change on a new branch in your fork.
3. Open a pull request to https://github.com/itznao/mida.

Your fork may be used **only** to prepare and send pull requests to this repository. Do not publish builds of it, share it, or keep it as a separate project.

## Your rights in your contribution

By sending a pull request, you agree that:

- You wrote the code, or you have the right to send it.
- iTz_Nao may use, change, license and distribute your contribution in MIDA, under any terms, without payment.

## Build and test

```bash
npm install
npm start
```

Run this in a second terminal while you change Tailwind classes:

```bash
npm run css
```
